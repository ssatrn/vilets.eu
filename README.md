A personal website for my projects, notes, activity and contact info.

### `01` — what's on it

- **Home** — intro, current activities and recent updates
- **Notes** — short writings organized by year
- **Contact** — email, links and a contact form
- **Themes** — dark and light mode, with saved preference
- **Responsive layout** — works on desktop and mobile
- **Accessibility** — keyboard navigation, reduced motion and print styles
- **Privacy** — no analytics, tracking or cookies

### `03` — run locally

```bash
git clone https://github.com/ssatrn/vilets.eu.git
cd vilets.eu
```

Open `index.html` in your browser. That's it.

### `04` — structure

```text

├── index.html
├── og.png
├── CNAME
```

Push changes to `main` to publish updates through GitHub Pages.
